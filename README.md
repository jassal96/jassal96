**Key engineering points**

* Indexed **24,154 candidate profiles** using semantic embeddings.
* Narrowed retrieval to the **top 2,000** candidates before deeper ranking.
* Built a hybrid candidate-ranking pipeline using multiple fit signals.
* Generated recruiter-style explanations using a Groq-hosted Llama model.
* Grounded generated explanations in retrieved candidate information.
* Added automatic **career-gap detection** for recruiter interpretation.
* Containerized the application using **Docker**.

## `03` — BioGAT-Rehab

### Physics-Informed Graph Attention Network for Rehabilitation Assessment

```text
                   HUMAN MOVEMENT
                         │
                         ▼
                 SKELETON KEYPOINTS
                         │
                         ▼
             ANATOMICALLY CONSTRAINED
                        GRAPH
                         │
                         ▼
                      GATv2
                         │
                         ▼
               TEMPORAL ATTENTION
                      / GRU
                         │
                         ▼
                MOVEMENT FEATURES
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
         Prediction             Uncertainty
                                    │
                            ┌───────┴───────┐
                            ▼               ▼
                       Epistemic       Aleatoric
                       MC-Dropout       Estimate
                            │               │
                            └───────┬───────┘
                                    ▼
                         LOW-CONFIDENCE CASE
                                    │
                                    ▼
                             CLINICIAN REVIEW
```

**Research direction**

* Spatiotemporal **GATv2 + temporal-attention/GRU** architecture.
* Anatomically constrained skeleton graph.
* Edge weighting combining **range-of-motion priors** and graph distance.
* **MC-Dropout** for uncertainty estimation.
* Separate **epistemic** and **aleatoric** uncertainty.
* Planned **ablation studies** and cross-dataset evaluation.
* Exploring **KIMORE ↔ UI-PRMD** generalization.

`PyTorch` `PyTorch Geometric` `GATv2` `GNN` `GRU` `MC-Dropout` `Uncertainty Quantification`
